\# Household Chores



A simple Django application for managing shared household chores between two people



The project focuses on being easy to understand, practical, and useful for non-technical users.



\## Main Features



\* One-time and recurring household chores

\* Assignment to one person, both people, or automatic rotation

\* Weekly and monthly calendar views

\* Completion tracking and simple monthly statistics
